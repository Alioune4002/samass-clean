# SAMASS

Site web réalisé pour un praticien massage, avec une présentation claire des prestations et un parcours de réservation en ligne.

**Site :** https://samassbysam.com

## Objectif

Donner aux visiteurs les informations utiles avant la prise de rendez-vous et réduire les échanges manuels autour des réservations.

## Projet

Le dépôt contient le frontend et le backend de l'application. Il s'agit d'un projet client présenté ici comme exemple de réalisation web pour une activité de service.
